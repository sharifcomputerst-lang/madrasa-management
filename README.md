# মাদরাসা ম্যানেজমেন্ট (সম্পূর্ণ অফলাইন)

মাদরাসা পরিচালনার জন্য সম্পূর্ণ অফলাইন অ্যান্ড্রয়েড অ্যাপ। ইন্টারনেট ছাড়াই সব কাজ করে এবং সব ডেটা ফোনেই সংরক্ষিত থাকে।

## ফিচারসমূহ
- নতুন শিক্ষার্থী ভর্তি (স্বয়ংক্রিয় ভর্তি নম্বর ও রোল)
- শ্রেণি অনুযায়ী পুরাতন শিক্ষার্থীর তালিকা (সার্চ/ফিল্টার, তালিকা PDF)
- শ্রেণি উত্তরণ (promote)
- পরীক্ষা ব্যবস্থাপনা ও শ্রেণিভিত্তিক বিষয়/পূর্ণমান সেটআপ
- নম্বর এন্ট্রি (গ্রিড আকারে, দ্রুত ইনপুট)
- সমন্বিত রেজাল্ট (GPA, গ্রেড, মেধাস্থান) — PDF
- শিক্ষার্থীভিত্তিক একক মার্কশিট — PDF (পুরো শ্রেণির একত্রেও)
- শিক্ষক ও শিক্ষার্থী হাজিরা (উপস্থিত/অনুপস্থিত/ছুটি)
- মাসিক পাঠদান ও হাজিরা রিপোর্ট — PDF
- মাসিক বেতন আদায়, বেতন শিট PDF
- বকেয়া বেতন হিসাব (বছরভিত্তিক) — বকেয়া তালিকা PDF
- শিক্ষক বেতন প্রদান ও বেতন শিট PDF
- ব্যাকআপ: স্ন্যাপশট, ব্যাকআপ ফাইল শেয়ার/সংরক্ষণ, ফাইল থেকে পুনরুদ্ধার, দৈনিক স্বয়ংক্রিয় ব্যাকআপ

## ইনস্টলেশন
1. `MadrasaManagement.apk` ফাইলটি ফোনে নিন (USB/শেয়ার)।
2. ফাইলটি ট্যাপ করুন। "অজানা উৎস" অনুমতি চাইলে দিন (Settings → Allow from this source)।
3. Install চাপুন — ইন্টারনেট ছাড়াই ইনস্টল হবে।
4. অ্যাপ খুলে **সেটিংস**-এ গিয়ে মাদরাসার নাম/ঠিকানা ও শ্রেণিগুলো যোগ করুন, তারপর ভর্তি শুরু করুন।

Android 7.0 (API 24) বা তার উপরের যেকোনো ফোনে চলবে।

## ডেটা ও ব্যাকআপ
- সব ডেটা অ্যাপের নিজস্ব সংরক্ষণাগারে (`db.json`) সংরক্ষিত হয় — অ্যাপ আনইনস্টল করলে ডেটা মুছে যায়।
- প্রতি দিন একবার স্বয়ংক্রিয় ব্যাকআপ (`bk-day.json`) নেয়।
- নিয়মিত **সেটিংস → ব্যাকআপ শেয়ার/সংরক্ষণ** থেকে JSON ব্যাকআপ নিয়ে রাখুন; প্রয়োজনে সেই ফাইল থেকে পুনরুদ্ধার করুন।

## রেজাল্ট PDF
রেজাল্ট/মার্কশিট/রিপোর্ট পেজে "প্রিন্ট" বাটন চাপলে সিস্টেম প্রিন্ট ডায়ালগ আসবে — সেখানে "Save as PDF" নির্বাচন করে সেভ করুন। বাংলা যুক্তাক্ষর সঠিকভাবে আসে (সিস্টেম টেক্সট ইঞ্জিন ব্যবহার হয়)।

## প্রযুক্তি
- Native Android shell (Java, AndroidX ছাড়া) + WebView-ভিত্তিক বাংলা UI
- সম্পূর্ণ অফলাইন — কোনো ইন্টারনেট অনুমতি নেই
- বিল্ড (Gradle ছাড়া): `tools/build.sh` — aapt2 + javac + d8 + apksigner

## প্রজেক্ট কাঠামো
```
AndroidManifest.xml
java/com/madrasa/management/   MainActivity (WebView shell), AppFileProvider
assets/app/                    index.html, style.css, helpers.js, app.js (বাংলা UI)
res/                           আইকন, strings
tools/                         build.sh, gen_icon.py
```
